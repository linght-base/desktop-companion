你在桌前忙自己的事，它会看看你，用眼神、转头和一句短话回应你。有些值得记住的瞬间，还会被画成漫画。

## 第一次使用

目前请在 Mac 上体验。先按[安装说明](INSTALL.md)完成准备，再从 WatcherRobot 启动“桌面伙伴”。

打开电脑上的 <http://127.0.0.1:8794/>。第一次使用先进入“初始化设置”，在“大模型设置”中，填写服务地址、模型名称和 API Key，点“保存并生效”。设置仅保存在这台电脑；已保存的密钥不会再次显示，以后留空即可保留。

保存设置会暂停陪伴。确认机器人已连接，进入“陪伴”页签点击“启动”，机器人会自动开启自己的摄像头并开始观察。

启动会把机器人画面交给你配置的 AI 服务处理，先将不想分享的内容移出镜头；需要时可以在画面上设置遮挡。

## 像平时一样做自己的事

不用给它布置任务，也不需要说话。你可以工作、看书、摆弄手边的小东西，留意它的眼睛和眼睛下方的短句。

它会结合之前看到的事继续回应你，可能给你一点鼓励，也可能对眼前的事表现出好奇。它偶尔会看错，反应也可能需要等一会儿。

找到你后，它会停在合适的位置。看不到你时会试着找一找；持续没人时，会休息一会儿，再定时看看。

## 看漫画和相处记录

网页的“值得回忆”里，可以看到它留下的漫画和一句鼓励。每半小时尝试画一个片段，最近最多保留五张；没看清楚时就先不画。想先试一张，可以点“画出最近的瞬间”。漫画是按记录画出的插画，细节可能和现场不同。

“如何理解你”页签展示认识与思考依据，“相处记录”页签展示看见的片段与经历；记错了可以更正或撤回。

## 停止与结束

- 想歇一会儿：点“停止”。回来后再点“启动”。
- 今天结束：点“停止”，也可以按 Esc。

**只关闭网页不会停止陪伴。离开前请明确点“停止”。** 从 WatcherRobot 停止作品会退出本作品启动的程序。

## 遇到问题

| 情况 | 怎么办 |
| --- | --- |
| 显示未连接 | 让机器人停在连接界面，在网页中用当前六位配对码重新连接。 |
| 看不到画面 | 到“陪伴”页点击“启动”；仍无画面时，到“初始化设置”检查机器人连接。 |
| 有眼睛但没有回应 | 确认已启动陪伴，让它看清你，稍等一会儿；查看页面有无网络或服务提示。 |
| 没有漫画 | 先让它留下相处记录，或点“画出最近的瞬间”，等待生成。 |
